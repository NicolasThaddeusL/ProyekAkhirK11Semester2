Project ini merupakan proyek akhir semester berbentuk website toko online sederhana bernama Notebook District. Website ini menampilkan halaman utama dengan tampilan modern, produk-produk alat tulis, navigasi antarhalaman, serta desain yang dibuat agar terlihat rapi dan mudah digunakan.

Ringkasan

Project ini adalah website toko online sederhana bernama Notebook District. Website ini dibuat sebagai proyek akhir semester dan menampilkan konsep toko alat tulis dengan halaman utama, produk, desain kartu produk, serta navigasi website.

Project ini juga menunjukkan penerapan HTML, CSS, dan JavaScript untuk membuat tampilan website yang lebih interaktif dan menyerupai website e-commerce sederhana.

Yang Dipelajari

  • Struktur website multi-halaman
  • Desain landing page toko online
  • Penggunaan card untuk menampilkan produk
  • Navigasi antarhalaman website
  • HTML, CSS, dan JavaScript untuk website interaktif
  • Hosting website menggunakan Netlify
