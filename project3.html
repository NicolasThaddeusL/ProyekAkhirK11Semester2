Project 3

Card Game

Latihan membuat card karakter game menggunakan Bootstrap.

Project ini menampilkan lima card karakter bertema game. Setiap card berisi nama karakter, gambar, level, statistik seperti HP/STR/DEX, serta progress bar EXP. Fokus utamanya adalah penggunaan Bootstrap card, grid, image placement, warna, dan progress bar.

Kembali ke Halaman Utama Lihat Preview Project Sebelumnya Project Berikutnya

Ringkasan

Project ini adalah latihan membuat card karakter untuk sebuah game berjudul Dungeons and Dragons: The Tale of Five Brothers. Setiap karakter memiliki data level, statistik, dan progress EXP.

Yang Dipelajari

  • Bootstrap card
  • Grid dan column layout
  • Card image top dan card image bottom
  • Progress bar animated
  • Utility warna, background, dan text alignment
