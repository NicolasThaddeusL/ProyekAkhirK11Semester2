Website “TahanTempur”

Nicolas Thaddeus Lilistyo 11A6/25

Dalam website “TahanTempur”, JavaScript tidak digunakan melalui file terpisah, melainkan melalui tag <script>. Kode JavaScript digunakan untuk membantu pengolahan data tahap awal pada bagian form.

Kode JavaScript

document.getElementById('form').addEventListener('submit', function(e) {
  e.preventDefault();

  alert('Registration submitted successfully!');

  console.log({
    name: document.getElementById('name').value,
    dob: document.getElementById('dob').value,
    country: document.getElementById('country').value,
    citizenship: document.getElementById('citizenship').value,
    passport: document.getElementById('passport').value,
    job: document.getElementById('job').value,
    tel: document.getElementById('tel').value,
    email: document.getElementById('email').value,
    amount: document.getElementById('amount').value
  });
});

Bagian-bagian Kode

1. Akses elemen form dari DOM

document.getElementById('form') digunakan untuk mengakses elemen HTML dengan id form. document adalah representasi halaman web, sedangkan getElementById() mengambil elemen spesifik berdasarkan id.

2. Menangani event submit form

.addEventListener('submit', function(e) { ... }) menambahkan event listener pada form. Event submit aktif ketika pengguna menekan tombol submit.

3. Mencegah perilaku default form

e.preventDefault() mencegah form melakukan reload halaman atau mengirim data langsung ke server. Dengan ini, halaman tetap berada pada posisi yang sama setelah form dikirim.

4. Menampilkan notifikasi ke pengguna

alert('Registration submitted successfully!') menampilkan pesan pop-up sebagai feedback bahwa form sudah berhasil dikirim.

5. Menampilkan data ke console

console.log({ ... }) menampilkan data ke console browser dalam bentuk object JavaScript.

6. Mengambil nilai input dari DOM

document.getElementById('name').value mengambil nilai dari input dengan id name. Cara yang sama digunakan untuk field lain seperti dob, country, citizenship, passport, job, tel, email, dan amount.

7. Menyusun data dalam object JavaScript

Data disusun dalam format key: value, misalnya name: ..., agar lebih mudah dibaca dan diproses.
